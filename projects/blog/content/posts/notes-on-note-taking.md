# Notes on note-taking

I've tried five apps. The system that finally stuck is one text file per month, no folders.

```text
notes/
  2026-08.txt
  2026-09.txt
```

Each line starts with a date. Searching is `grep`. It's not elegant, but I've kept it for four months, which is a record.

## Why it works

1. Nothing to organize
2. Nothing to migrate
3. Nothing to break
