Static sites.
Native speed.

NeyX is a static site generator compiled straight to native code with the Salam programming language. No Node, no Ruby, no runtime to install - write Markdown, render it with a tiny template language, and ship a site that builds before you finish reading this sentence.

Everything included

One binary, batteries included.

No plugins to install, no config to wire up before you get a working site.

Markdown + front matter

Write content in Markdown with YAML front matter - title, description, dates, tags, drafts.

Tiny template language

{{ value }}, {{ if }}, {{ each }} - no build step, no JSX, no new syntax to learn.

Multi-language sites

Split content per language, get hreflang alternates and {{ lang }}/{{ dir }} for free.

Tags & taxonomies

Tags, categories, or any custom field - NeyX builds term pages and indexes automatically.

RSS, Atom & Sitemap

feed.xml, atom.xml, sitemap.xml and robots.txt, generated on every build.

Responsive images

JPEG/PNG variants at 480 / 960 / 1440px, generated automatically during the build.

Built-in client search

A dependency-free JS search widget backed by a generated search-index.json.

Pagination & drafts

Paginate listings, keep drafts out of production builds, preview them with --drafts.

Live dev server

neyx dev watches content, layouts, assets and data - rebuilds and serves instantly.

Doctor & check

neyx check catches broken links and missing alt text; neyx doctor diagnoses project issues.

Build hooks

Run shell commands via before_build and after_build - wire up your own pipeline.

Themes

Fall back to a shared theme's layouts and assets - override only what your site needs to change.

Command line

A CLI that gets out of your way.

Everything you need for a static site, in one small tool.

# scaffold a new project
$ neyx new my-site
cd my-site

# create a dated post under content/posts/
$ neyx new post "Hello, NeyX"
# build, serve, and rebuild on every change
$ neyx dev

# minified production build
$ neyx build --pretty

# serve an existing dist/ build
$ neyx preview
# broken links, missing assets, missing alt text
$ neyx check

# diagnose common project problems
$ neyx doctor

# time 3 repeated builds, report throughput
$ neyx benchmark

Prefer to build it yourself?

$ git clone https://github.com/BaseMax/neyx.git
$ cd neyx
$ salam build
$ ./neyx new my-site

Requires the Salam compiler on your PATH.
